# xkernel: StarryX 宏内核

`xkernel` 是 `StarryX` 的宏内核实现。它统一拥有内核状态、服务实现和 Linux 系统调用边界，避免原 `xcore` 与 `xapi` 之间只有形式上的 crate 分层。

这包括但不限于：

*   **内存管理：** 处理系统的虚拟内存和物理内存。
*   **任务管理：** 创建、调度和管理任务（进程和线程）。
*   **IPC（进程间通信）：** 为进程之间的通信提供机制。
*   **系统调用接口：** `syscall` 子模块处理 Linux ABI 解码、用户参数转换和 trap 回调。
*   **文件系统抽象：** 为不同的文件系统提供统一的接口。

`xkernel` crate 位于 `xkernel/` 目录中，是 `StarryX` 架构的核心部分。

## 核心组件

`xkernel` 包含几个关键的子模块，它们共同构成了操作系统的核心功能：

*   **`fs` (文件系统):** 提供文件系统抽象和虚拟文件系统 (VFS) 支持。
*   **`ipc` (进程间通信):** 实现消息队列、信号量和共享内存等 IPC 机制。
*   **`mm` (内存管理):** 管理虚拟内存、物理内存和页缓存。
*   **`net` (网络):** 提供网络协议栈和套接字 API。
*   **`sys` (系统):** 包含系统级功能，如资源管理和时间。
*   **`task` (任务管理):** 负责进程和线程的创建、调度和信号处理。
*   **`syscall` (Linux ABI):** 包含文件、内存、任务、IPC、网络及系统类 syscall 的实现和统一分发。

依赖方向固定为 `syscall -> kernel services -> xmodules / xcore`。`xmodules` 不依赖 `xkernel`，从而保持组件可复用性。
