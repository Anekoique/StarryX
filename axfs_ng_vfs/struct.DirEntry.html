Struct DirEntry

Source 
pub struct DirEntry<M>(/* private fields */);
Expand description

A directory entry that can represent either a file or directory

This is the primary abstraction for filesystem nodes in the VFS. It contains both the node implementation and metadata about the node’s location in the filesystem hierarchy.
